# Asset layout

- `chr/`: character model and texture assets
- `stg/`: battle-stage assets
- `ui/`: menu and HUD assets
- `eft/`: visual effects
- `snd/bgm/`: background music
- `snd/se/`: sound effects
- `snd/voice/`: voice assets
- `common/`: shared resources

These folders organize files; they do not imply that every format or resource type is already loaded by the game. Use original or properly licensed assets and document formats before implementing loaders.

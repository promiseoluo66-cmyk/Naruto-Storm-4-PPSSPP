# Character assets

Each character gets a stable ID folder, for example `naruto/`, `sasuke/`, or `sakura/`. Keep model, texture, costume, and character-specific jutsu resources grouped by character:

```
chr/
  naruto/
    model/
    textures/
    costumes/
    jutsu/
  sasuke/
    model/
    textures/
    costumes/
    jutsu/
```

See `_template/` for the documented starter structure. This is the planned layout; it does not mean character models, clothing, jutsu files, or runtime loaders already exist. Use original or properly licensed assets. Do not copy files from commercial game ISOs.

# Game data

Data-driven definitions loaded by the engine (src/character.c, src/story.c).

Status: DATA ONLY. Values are first-pass balance numbers, untested in-game.

## Input mapping used in move definitions
- circle: basic attack, square: ninjutsu 1, square+up: ninjutsu 2
- triangle: chakra charge, triangle+circle (full gauge): ultimate
- l+r+triangle (awakening gauge ready): awakening / transformation
- x+direction: chakra dash, l+x: substitution
